# HF-VORTEX-DRIVER

Hardware-agnostic C++20 library for **HardFOC Vortex** communication over **CAN** (NMT, expedited SDO, and named CiA 402 / vendor indices). Transport is **injected** via `VortexCanTransport` (HAL implements with `BaseCan`).
