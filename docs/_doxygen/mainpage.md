# Vortex Driver API reference {#mainpage}

The classes, members and constants of the HardFOC Vortex driver, generated from the headers.

Start with hf::vortex::VortexHostSession, the client, and hf::vortex::VortexCanTransport, the interface your
transport implements. The NMT commands and object constants are in the hf::vortex namespace.

The guides, with code that is compiled and checked, are on the documentation site: <a href="../">Vortex Driver
documentation</a>.
