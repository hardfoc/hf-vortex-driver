Detailed Description

CiA 301/402 and HardFOC vendor index placeholders for Vortex over CAN.

Values are documentation and compile-time defaults; the final Object Dictionary (CANopenNode or product EDS) is authoritative. This header keeps host and device firmware aligned on named constants without pulling in CANopenNode.
